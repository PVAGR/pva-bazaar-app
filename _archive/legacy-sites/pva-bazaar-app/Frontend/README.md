# Journal Website

This project is a simple journal website built using React. It allows users to view journal entries, search through them, and learn more about the project.

## Project Structure

```
pva-bazaar-app
├── Frontend
│   ├── index.html          # Main HTML file that loads the React app
│   ├── public
│   │   ├── app.js         # Main JavaScript file for the React SPA
│   │   └── styles         # Directory containing CSS files
│   │       ├── base.css
│   │       ├── theme.css
│   │       ├── home.css
│   │       ├── journal.css
│   │       ├── entry.css
│   │       ├── about.css
│   │       └── search.css
│   ├── src
│   │   └── data
│   │       └── entries.js # JSON file containing journal entries
│   ├── package.json       # Project dependencies and scripts
│   └── README.md          # Project documentation
```

## Getting Started

To get started with the project, follow these steps:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/PVAGR/pva-bazaar-app.git
   cd pva-bazaar-app/Frontend
   ```

2. **Install dependencies:**

   ```bash
   npm install
   ```

3. **Run the development server:**

   ```bash
   npm run dev
   ```

4. **Build the project for production:**
   ```bash
   npm run build
   ```

- View journal entries
