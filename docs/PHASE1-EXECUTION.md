# Phase 1 Execution Checklist

Use this alongside `VENTURE-ROADMAP.md` and the product/Etsy/OPS docs. Tick or date items as you go. To deploy the sanctuary app first, see [DEPLOY-SANCTUARY.md](./DEPLOY-SANCTUARY.md).

## Week 1 – Stand up product + Etsy

- [ ] Lock 4–5 SKUs with real artisans (use `PRODUCT-SOURCING-KENYA.md`; note MOQ, cost, lead time).
- [ ] Fill a private inventory sheet from `OPS-INVENTORY-TEMPLATE.csv` with real numbers.
- [ ] Publish 4–5 Etsy listings (copy/adapt from `ETSY-LISTINGS-KENYA.md`).
- [ ] Have `OPS-ORDER-WORKFLOW.md` and `OPS-CUSTOMER-MESSAGES.md` to hand for first order.

## Weeks 2–4 – Run the loop

Each week:

- [ ] Process every order with the workflow; adjust the workflow doc if a step is wrong or missing.
- [ ] Add 1–3 bullets to **Decision log** in `VENTURE-ROADMAP.md` (what you did, what you decided).
- [ ] Optional: set a small weekly order target (e.g. 2, then 3, then 5) and track in the roadmap.

## When the sanctuary app is live

- [ ] Use `/archive` as the “story layer” when writing Etsy copy or talking to artisans.
- [ ] After you log verification records in the backend, use `/verification` (single ID) and `/dashboard` (multiple IDs) to spot-check artifacts.
