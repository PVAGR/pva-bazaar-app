🔗 OpenClaw Health Widget Examples

Auto-Initialized (Full)

Uses data attributes for configuration:

<div id="openclaw-health-widget" data-api-url="https://api.pvabazaar.org" data-refresh-interval="60000" data-show-details="true"> </div>

Compact Widget

Minimal inline display:

<div id="openclaw-compact" data-compact="true" data-show-details="false"> </div>
System Status:

Manual Initialization

Programmatic control:

<div id="openclaw-manual"></div> <script> OpenClawWidget.init({ apiUrl: 'https://api.pvabazaar.org', refreshInterval: 30000, showDetails: true }); </script>

API Methods

Programmatic control examples:

// Initialize widget OpenClawWidget.init({ apiUrl: 'https://api.pvabazaar.org' }); // Manual refresh OpenClawWidget.refresh(); // Get current status const status = OpenClawWidget.getStatus(); console.log(status); // Destroy widget (stop auto-refresh) OpenClawWidget.destroy();
